# TIRAN API

TIRAN v1 documents only APIs that are actually implemented.

| Command | Purpose |
|---|---|
| `say` | Console output |
| `let` | Variable declaration |
| assignment | Variable update |
| `if` / `else` | Branching |
| `repeat` | Counted loop |
| `while` | Conditional loop |
| `function` | Function definition |
| `call` | Function call |
| `return` | Function return |
| `break` | Leave a loop |
| `continue` | Skip a loop iteration |
| `create part` | Roblox Part creation |
| `service` | Roblox GetService |
| `set` | Roblox/Lua property assignment |

The API is intentionally extensible. New APIs are added only when their compiler behavior and documentation are implemented.
